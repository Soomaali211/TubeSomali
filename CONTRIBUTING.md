# Contributing
- Only the phase authorized by the owner may be worked on. Do not push, publish, deploy or release without explicit authorization.
- Never commit secrets; `.env.example` holds placeholders only. Do not log subtitle text, tokens or private media.
- No ASR/Whisper. YouTube mode = official embed only (no audio, overlays or scraping).
- Do not weaken gates or tests; a test is PASS only with recorded evidence.
- Run the local checks in README before committing.
